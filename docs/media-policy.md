# Leaguepedia 圖片展示政策

2026-10-04 使用者批准 `leaguepedia-editorial-v1`：非商業賽事資料展示可採用
經審閱的 Leaguepedia 選手定裝照與戰隊隊標。圖片使用依據與授權分開記錄；
fair-use 聲明或沒有逐檔授權的圖片均不得標示為 CC 授權。

每個公開圖片需保留精確圖片頁、來源版本、發布圖片 SHA-256、可得的權利聲明、
來源署名及審閱紀錄。未具名攝影師或畫師要明示來源頁未提供，不推測作者。
審閱清單在 `data/overrides/media.json`；選手 UUID、來源頁及戰隊年代需精確對應。
同一戰隊的現代隊標不能覆蓋其他歷史年代。區域圖示保持原有呈現。
發布可使用來源 API 提供的 512px 縮圖；原檔 SHA-1 與縮圖 SHA-256 分開保存，
不將縮圖雜湊宣稱為原檔雜湊。固定格式並驗證實際發布內容，保留圖片比例。

`pnpm data media` 只發布已審閱的圖片，不更新比賽、名單或覆蓋範圍。
圖片經限量下載並校驗後保存在既有 object store；GitHub Actions `media` 模式
透過驗收、新的私有 checkpoint 及同源 Pages 檔案部署。圖片內容變更後需要
重新審閱校驗碼；未審閱、缺失、歧義或校驗失敗的圖片不會取得發布資格。

網站「圖片來源與權利聲明」頁列出實際公開圖片、來源與使用依據，並提供
維護者聯絡入口。權利仍屬各自權利人；本政策不是權利人授予的再散布授權。
圖片來源有誤或收到移除要求時，維護者應更新審閱清單與當前圖片發布狀態，
經正常 checkpoint／Pages 發布流程處理；保留部署及來源稽核紀錄。

此政策取代 ADR-0001 對這些明確審閱資產的 licensed-only 限制。
既有具授權圖片仍有效。來源證據與審閱條件未滿足的圖片使用生成圖示。
