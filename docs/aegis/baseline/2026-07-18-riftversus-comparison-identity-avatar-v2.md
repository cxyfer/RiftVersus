# RiftVersus comparison identity and canonical avatar v2 baseline

Date: `2026-07-18`
Decision record: [ADR-0001](../adr/ADR-0001-leaguepedia-facts-and-fail-closed-presentation.md)

This snapshot records the verified runtime architecture and release evidence for
typed player identity, historical team rows, and canonical avatar v2. It is
evidence of current state, not completion authority.

## Owners and contracts

- Leaguepedia remains the sole facts provider. The publication boundary stores
  player `player_id` separately from `canonical_name`; search presents `ID (real
  name)` when both are available.
- Comparison subjects retain their selected canonical labels. Historical rows
  resolve the participating team or team-era names, never the selected player,
  region, or current affiliation.
- Licensed retained media keeps precedence. Otherwise Fastify generates the
  deterministic v2 SVG at `/avatars/v2/{kind}/{canonical-entity-id}.svg` using a
  validated two- or three-character ASCII abbreviation. Known regions use
  distinct reviewed styles; player/team styles do not inherit region styling.
- v2 responses use checksum ETags and `Cache-Control: public, no-cache` so a
  later typed player ID can revalidate the same URL. Generated bytes are not
  persisted as media provenance or source evidence.
